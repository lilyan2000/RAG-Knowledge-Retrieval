# RAG‑Knowledge‑Retrieval
基于 Python + Flask 构建的轻量级 RAG 知识库检索问答系统，适配机器学习教材文档，解决封面误召回、答非所问、对话历史污染等问题，支持双阈值检索与一站式缓存管理。

---

## ✨ 核心功能
- 教材专属问答：仅解析正文内容作答，屏蔽封面、版权、目录等无效信息，禁止编造内容
- 双阈值检索：区分**严谨模式**与**联想模式**，兼顾问答准确性与上下文追问能力
- 缓存机制：文本分片、向量数据、对话历史持久化存储，支持一键清空缓存
- 上下文对话：自动留存历史问答，实现多轮连贯对话
- 格式约束：输出统一纯文本排版，无 Markdown 格式符号

---

## 🛠️ 技术栈
- 后端框架：Python、Flask、Flask‑CORS
- 核心能力：自定义 RAG 框架、文本分片、向量嵌入、余弦相似度检索
- 数据存储：NumPy（向量）、JSON（文本分片/对话记录）
- 依赖模块：大模型接口、向量嵌入接口、通用工具函数

## 🚀 快速启动
### 1. 安装依赖
```bash
pip install flask flask-cors numpy
```

### 2. 基础配置
1. 将教材 PDF 文件放置到 `tests/MLbook.pdf` 路径下
2. 检查 `llm.py`、`embedding.py` 内接口密钥、服务地址配置

```bash

```

## 📖 核心配置说明
### 1. 双阈值检索模式
- 严谨模式（默认）：阈值 `0.38`，高过滤强度，适用于名词定义类问题
- 联想模式：阈值 `0.25`，放宽检索条件，适用于上下文追问场景

代码切换方式：
```python
rag.set_mode("strict")  # 切换为严谨模式
rag.set_mode("loose")   # 切换为联想模式
```

### 2. 缓存管理
- 缓存目录：`rag_db/`，包含文本分片、向量数据、对话历史文件
- 代码清空缓存：调用 `rag.clean_all_cache()`，同步清空缓存文件与内存数据
- 手动清理：直接删除 `rag_db` 文件夹，重启项目重新生成缓存

### 3. 基础参数
```python
self.thresh_loose = 0.25   # 联想模式阈值
self.thresh_strict = 0.38  # 严谨模式阈值
self.top_k = 3              # 单次检索返回分片数量
self.chunk_size = 500       # 文本分片字符大小
self.overlap = 80           # 分片重叠字符数
```

## 🎯 使用示例
### 1. 常规问答（严谨模式）
- 提问：`机器学习是什么`
- 效果：提取教材标准定义，补充相关知识点，不罗列目录

- 提问：`计算机网络是什么`
- 效果：输出 `【知识库无相关内容】`，自动过滤无关内容

### 2. 多轮追问（联想模式）
基于上一轮问答继续提问，系统结合上下文检索相关内容并作答。

## ❓ 常见问题
### 1. 回答内容混乱、出现封面信息
原因：旧缓存残留 + 错误对话历史污染，且未重启服务
解决：关闭程序 → 删除 `rag_db` 文件夹 → 重启项目，执行缓存清空方法。

### 2. 相同问题答案不一致
原因：严谨/联想两种检索模式阈值不同，检索范围有差异
解决：定义类问题使用严谨模式，追问场景使用联想模式。
